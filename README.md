# AWS Cloud Infrastructure Automation

A collection of production-ready Python automation scripts leveraging the Boto3 library to automate daily cloud management, backup tasks, and logging operations on AWS.

## Features
- **Automated EC2 Backups:** Automatically creates EBS snapshots of active instances.
- **S3 Log Management:** Automatically uploads local system logs to AWS S3 buckets for centralized storage.
- **Cost Optimization:** Scripts to identify and clean up unattached EBS volumes to save cloud costs.

## Tech Stack
- **Language:** Python
- **Cloud Provider:** Amazon Web Services (AWS)
- **Libraries:** Boto3, Botocore
